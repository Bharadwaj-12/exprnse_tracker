# 💰 Expense Tracker

A lightweight, user-friendly Python application designed to help individuals monitor their daily spending, track expenses by category, and stay on top of their personal budget.

## 🚀 Features
* **Quick Entry:** Add new expenses with costs, categories instantly.
* **Smart Categorization:** Group spending into categories like Food, Rent, Utilities, and Entertainment.
* **Budget Summary:** Get a fast overview of your total expenditures to see where your money goes.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Data Storage:** JSON

## 📦 How to Run the Project Local Layout

### Prerequisites
Make sure you have Python installed on your computer. You can download it from [python.org](https://python.org).

### Setup Instructions
1. **Clone or Download the Project:**
   Click the green **Code** button at the top of this GitHub page and select **Download ZIP**, then extract it.
   
2. **Open and Run:**
   Open your terminal, command prompt, or PyCharm terminal inside the project directory and run:
   ```bash
   python main.py
   ```
